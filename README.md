One line roasting an alarm clock that rings at 6 AM on a Saturday morning. The program writes the roast to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Set a different output file with the `OUTPUT_PATH` environment variable:

```sh
OUTPUT_PATH=/tmp/entry.txt python3 main.py
```
